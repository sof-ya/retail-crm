# Retail CRM

CRM-система для управления розничной торговлей: товары, склады, заказы, поставки, перемещения, клиенты.
## Быстрый старт

### Автоматический запуск

```bash
git clone <url> retail-crm
cd retail-crm
./start.sh
```

Скрипт установит зависимости, поднимет контейнеры, выполнит миграции, сгенерирует Swagger и запустит фронтенд.

---

### Движения остатков

Таблица `stock_movements` записывается при:
- **Создании заказа** — резерв (отрицательное quantity)
- **Обновлении позиций заказа** — отмена старых + новые резервы
- **Завершении заказа** — списание
- **Создании поставки** — приход (положительное quantity)
- **Создании перемещения** — списание со склада-отправителя + приход на склад-получатель

Использует полиморфную связь: `doc_type` (Order/Supply/Transfer) + `doc_id`.

## API

Базовый путь: `/api`

Swagger UI доступен по адресу: `/api/documentation` (после генерации документации).

### Генерация Swagger

```bash
./vendor/bin/sail artisan l5-swagger:generate
```
